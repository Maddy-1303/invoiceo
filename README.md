## Download

Get the free installers for Windows 10 and 11, macOS 12 or later, and Linux (.deb for
Ubuntu, Debian and Linux Mint, or an AppImage) from the
[Invoiceo download page](https://invoiceo.in/download.html), with step-by-step install help.

## Features

- Invoices, quotations and receipts with PDF templates (A4, A5, A6 and thermal receipts)
- Customers, products and services with stock tracking and barcode scanning
- Tax (GST / VAT) handling, discounts, additional charges and round-off
- Payments and outstanding balances, reports and exports
- Thermal receipt printing with automatic printing to the saved printer
- Multiple companies, multiple users, backup and restore
- Languages: English, Tamil (Beta), Hindi, Nepali, Tibetan, French, Spanish and Chinese

More on the [Invoiceo billing software website](https://invoiceo.in/).

## Privacy

Your customers, products and invoices stay on your own computer. The app sends a few
anonymous usage counts (a random ID, the app version and the operating system), which you
can turn off under Settings → Software Info. Details are in the
[privacy policy](https://invoiceo.in/privacy.html).

## Build from source

```bash
flutter pub get
flutter run -d windows     # or macos / linux
```

Release installers are built by the GitHub Actions workflow in `.github/workflows/build.yml`
when a `v*` tag is pushed.
